# ReactNativeTBDD

A TypeScript project focused on Test-Driven Development (TDD) for React Native applications.

## Overview

This repository demonstrates best practices for implementing Test-Driven Development in React Native projects. It serves as a reference implementation for building reliable, well-tested mobile applications using React Native and TypeScript.

## Tech Stack

- **Language**: TypeScript 100%
- **Runtime**: Node.js (>=18.0.0)
- **Build Tool**: tsx (TypeScript Execute)
- **Build/Bundle**: esbuild

## Getting Started

### Prerequisites

- Node.js 18 or higher
- npm or yarn package manager

### Installation

```bash
npm install
```

This will install all required dependencies, including:
- `tsx` - TypeScript executor for running TypeScript files directly
- `esbuild` - Fast JavaScript/CSS bundler and minifier

## Development

### Running Tests

```bash
npm test
```

Currently, the test script is configured as a placeholder. Update it with your testing framework of choice (Jest, Vitest, etc.).

## Project Structure

The repository is organized using TypeScript for all source files. The project utilizes tsx for direct TypeScript execution without requiring a build step.
